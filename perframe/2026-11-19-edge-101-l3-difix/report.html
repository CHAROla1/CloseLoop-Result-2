方法附录

GT为人类参考轨迹；s为沿路线里程；d为横向偏差；RMSE为均方根误差。下方保留原指标方法、阈值与局限，具体展示单位以各模块为准。

展开对齐、分档及原有指标方法

指标定义与计算方法按四个评测问题组织：加减速吻合 · 转向时机幅度 · 场景理解 · 贴合进度

⓪ 前提：对齐与 s 域重采样（所有指标的地基）

闭环里策略一偏离，后续观察全变，且 100 帧内策略与 GT 行驶里程通常不同——按时间 t 逐帧对比会把"开得慢"错判成"到处都不对"。因此：

  • 时间对齐：所有跨文件对齐用绝对 timestamp_us；对比窗 = [ego 起点 1.2s, 双方共同结束时刻]（前 1.2s 是 log-replay warmup，不参与）。
  • Frenet 投影：把 ego 每帧投影到 GT 路径折线上，得里程 s（沿路走了多远, m）与带号横向偏差 d（偏离 GT 路径多远, m，左正右负）。注意 d 是到整条 GT 路径的空间距离，与 GT 此刻在哪无关——落后 30m 但仍在这条路线上不算发散；进度差由 s 单独承担（进度比）。若需"同时刻位置差"，对应平台指标 dist_to_gt_location，本报告发散判据对齐的是 dist_to_gt_trajectory 思路。边界情况：切弯时投影可能跳段，发散时刻在该类场景有±误差。
  • 里程域重采样：两条轨迹都按 Δs=0.5m 网格插值，之后"曲线类"指标全部是 s 的函数——含义变为"走到同一地点时，做的事一不一样"，与整体快慢无关。
  • 发散截断：横向偏差 |d|>2.5m（≈一条车道宽）连续 5 帧（0.5s） 判发散——单帧超阈可能是正常借道/避让后马上回正，持续超阈才算真的路线分岔。发散后的帧不参与形状类指标（v/a/κ 曲线与事件对比从此截断；发散本身单独计为指标）；但 碰撞 / offroad / 进度不截断，全程计算。
  • 求导方式：速度/加速度/曲率全部由轨迹位置经 1.1s 平滑后差分（两侧同一 pipeline；ego csv 自带 acceleration 列单位可疑，未采用）。
① 加减速曲线吻合度 —— 三层衡量
a(s) RMSE〔① 加减速·曲线〕曲线层。同一位置处的加速度差均方根。加速度不用时间轴，由链式法则换成里程域：a(s) = ½·d(v²)/ds（数值上比 v·dv/ds 稳，刹车到停止也成立）。含义："GT 在弯前 20m 开始减速，你是否也在那里减速"。<0.5 很好，>1.2 明显走样。
a 分布 W1〔① 加减速·风格〕分布层。时域全帧加速度值各自排序成分布，取 100 个等距分位数逐点做差的平均（一维 W1 的闭式解）——衡量"驾驶风格像不像"（急/缓），对进度差和发散完全免疫。为什么选 W1 而非 KL/JS/KS：量纲与 a 相同，数值直接读作"平均每个分位挪多少 m/s²"（整体平移 δ 则 W1=δ）；无需直方图分箱（短窗口样本分箱不稳）；不要求分布支撑重叠（GT 未出现过的加速度区间 KL 会发散）；线性加权比 W2 抗离群急刹；且纯 python 10 行可算。局限：只比边缘分布、丢时序——"风格"归它管，"在哪踩"归 a(s) RMSE 与事件层。<0.3 风格接近。
jerk RMS〔① 加减速·平顺〕加加速度（加速度变化率）da/dt 的均方根（m/s³），平顺性/舒适度——"顿挫感"的直接来源。判读必须与同场景 jerk GT 成对比较（不同场景基线不同）：请结合下方当前批次的 jerk ego 与 GT 均值判断，不能仅凭单侧值归因。
刹车帧占比〔① 加减速·保守度〕a<−1 m/s² 的帧比例。ego/GT 之比是"过度保守"最直接的证据，需结合事件匹配与具体场景判断。
制动事件
(onset/峰值/漏/误)〔① 加减速·时机+幅度〕
制动响应率(%) = 匹配数/GT事件数		事件层。s 域检测制动段（a<−1 持续≥3m），GT↔ego 按 Δs≤10m 匹配：onset |Δs| = 开始刹车的位置差（时机，可换算 Δt≈2Δs/(v₁+v₂)）；峰值差 = 最大制动强度差（幅度）；漏 = 该刹没刹，误 = 不该刹瞎刹。
② 转向时机与幅度吻合度
κ(s) 曲率〔② 转向·信号〕转向的统一信号：κ = dψ_切线/ds（路径切线角对里程的变化率, 1/m；κ=0.015 即转弯半径 67m）。GT 无方向盘角记录，故两侧都用轨迹导出的曲率，同源可比。
横向机动事件〔② 转向·事件定义〕|κ|>0.015 持续≥3m 为一个横向机动；事件内总航向变化 Δψ≥20° 判转弯，航向回正且横向净位移≥2.5m 判变道。
时机 = onset |Δs|〔② 转向·时机〕GT 与 ego 机动开始位置之差（米）。0–2m 基本同步；>5m 说明明显早转/晚转。换算成时间：Δt ≈ 2Δs/(v_ego+v_gt)。
幅度 = 峰值κ差 + Δψ差〔② 转向·幅度〕机动峰值曲率之差（转得急不急）与整个机动航向变化量之差（转得够不够）。
漏 / 误〔② 转向·执行完整性〕
机动完成率(%) = ego机动数/GT机动数		漏 = GT 有机动 ego 没有（该转没转）；误 = ego 无中生有的机动。注意：窗口截断可能影响事件识别，需逐任务核验。
③ 场景理解准确率 —— 现状与目标口径
现状（代理）〔③ 场景理解〕本轮尚无直接"理解准确率"，用两个代理：VLM 推理文本的实体提及（车辆数/行人）→ 复杂度评分的动态维度；机动完成情况（漏做率）→ 行为侧的理解失效证据。
目标口径
（需周车真值）〔③ 场景理解〕		从场景真值（agents.json + 信号）自动提取事件表：前车急刹 / cut-in / 汇入冲突 / 红灯 / 停让……每类事件定义确定性响应判据 + 时间窗（如"前车 1s 内减速>2m/s² → 自车 2s 内 a<−0.5"），对每个事件判定策略响应正确/无响应/错误响应，输出 per-class 响应正确率 + 响应延迟（vs 人类司机）——即可量化的场景理解准确率。
碰撞 / offroad 任务率〔③ 安全·响应 / 规则理解〕发生该事件的任务数 ÷ 档内任务总数。数据源为平台逐帧布尔量 collision_any / offroad，全程任意一帧触发即计 1（不因发散截断）；碰撞 = 与任何物体接触（另有 front/lateral/rear 细分），offroad = 驶出可行驶区域。以"任务"为单位即场景级失败率；每档样本 1~5 个时置信区间宽，看方向不看精度。
已有近似〔③ 场景理解·规则〕违规类平台指标（offroad / wrong_lane / 压线）可视为"规则理解"的硬判据；机动完成率是"场景读对但没执行"的下界。
④ 贴合与进度（支撑指标）
无发散比例 / 发散时刻〔④ 贴合·持续度〕轨迹贴合能维持多久。无发散比例 = 首次发散前的时长 ÷ 总时长（实际帧数见当前数据，自 1.2s 起；从未发散记 1.0）；发散时刻 = 自 1.2s 起算到首次触发发散的秒数。本身即"开得像不像"的第一判据。注意：发散 ≠ 失败——发散后策略可能自己开得也好，只是与该人类司机走的已不是同一条路线；发散只截断"与 GT 对齐比较"类指标，安全/进度类指标不受影响。
|d|<1m 帧占比 / d RMSE / P90〔④ 贴合·路径〕
占比 = 发散前 |d|<1m 的帧比例(%)
RMSE = 发散前里程网格上 d 的均方根(m), GT 自身 d≡0 故无需做差
P90 = |d| 的 90 分位, 抓最坏段; 标尺: <0.5 贴 / 0.5~1.0 正常 / >1.5 晃		发散前窗口内横向偏差的均方根 / 90 分位（m）。路径形状贴合度；P90 抓"最坏的一段"。
v(s) 一致率 / RMSE〔④ 贴合·快慢剖面〕
一致率(%) = 共同里程网格上 |Δv|<2m/s 的点占比		共同里程段上同一位置的速度差（m/s）——快慢剖面吻合度（在哪该快在哪该慢）。数值需结合当前类别与速度剖面判断。
进度比〔④ 进度〕共同时刻窗结束时 s_ego / s_gt：1.0 = 与人同速；<0.8 常见原因是犹豫/无谓刹停/该走不走。可与平台 progress_rel_to_total 对照，相关性需按当前批次另行验证。
